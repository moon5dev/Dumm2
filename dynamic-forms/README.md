# Dynamic Forms

Dynamic Forms is a web-based dynamic report and document product.

The product starts with form template authoring, manual input, clipboard image/chart paste, and browser-based printing. Its long-term goal is to become a dynamic reporting system that can bind external data sources to reusable report templates.

## Current Focus

The current focus is the v0.1 Form Template MVP.

```text
Form Template MVP
+ temporary user workspace
+ clipboard image/chart paste
+ multi-template print bundle
- server-side document storage
- external data binding
```
